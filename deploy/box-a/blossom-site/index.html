Deepmarks Blossom

Archive storage for Deepmarks lifetime members.

Deepmarks uses Blossom as high-availability storage for archives created by our archive worker. The server is public-read by content hash, but direct uploads are restricted to Deepmarks infrastructure.

Archive-only write policy

Users do not upload arbitrary files to this server. When a lifetime member bookmarks a webpage or PDF with archiving enabled, Deepmarks captures the archive and stores the resulting bytes here. If a lifetime member buys the media archive add-on, Deepmarks uses yt-dlp, ffmpeg, or direct-file capture to archive supported bookmarked video and audio pages privately.

Server URL https://blossom.deepmarks.org
Writes Only the Deepmarks archive worker can upload or delete blobs.
Archives Webpages and PDFs are capped at 150 MB. Paid private media archives are capped at 2 GB.
