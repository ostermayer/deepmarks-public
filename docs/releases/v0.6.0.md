# Deepmarks 0.6.0

This release documents and ships the privacy-preserving publish model
across the web app and browser extensions.

## Publish model

- Clients sign Nostr events locally.
- The web app, mobile-capable frontend, share extension, and browser
  extensions POST signed bookmark events to the Deepmarks API by
  default.
- Deepmarks publishes accepted events to `relay.deepmarks.org`, then
  fans them out to the user's relay list.
- Public relays see Deepmarks' server IP, not the user's browser or
  phone IP.
- Browser extensions keep an advanced direct-publish mode for users who
  explicitly want to publish straight to their write relays.

## Browser extensions

- Chrome and Firefox extension packages are included in the project.
- Extension settings use the same synced account-settings model for
  relays, default tags, visibility, archive defaults, Blossom backups,
  and theme.
- Device-local secrets stay out of account settings: nsec storage and
  saved signer grants remain local. NWC credentials also stay local
  because the URI includes a wallet spending credential.

## Web and settings

- Settings sections now share the same layout treatment across web,
  mobile web, and the Capacitor shell.
- Nostr Wallet Connect is visible as a normal settings section rather
  than hidden under Advanced.
- Mobile app push notifications are marked as coming soon; current push
  support remains web push.
- iOS keyboard avoidance keeps focused text fields above the keyboard.

## Mobile source

The iOS and Android Capacitor projects remain in the public source tree
for audit and contributor work. Mobile app binaries are not part of the
0.6.0 public release, and the mobile apps should not be treated as
store-ready yet.
