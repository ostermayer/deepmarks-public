# Deepmarks 0.7.0

Deepmarks 0.7.0 is a public source release for the June 2026
sync/durability review work shipped in the installed app and
browser-extension 2.2.0 build line. The public source tag remains on
the 0.x stream; the native app and extension stores use their own
monotonically increasing versions.

Reliability fixes (each locked in by a regression test — see
`tests/README.md`):

- Private bookmark saves, edits, and deletes refuse to rewrite the
  encrypted set when any chunk failed to decrypt, instead of silently
  republishing the set without those entries and erasing them on every
  device. The browser extension additionally refuses rewrites after a
  failed or implausibly-empty relay read and recovers partial chunk
  generations with the same cross-version union as the web app.
- Private bookmark deletes propagate across devices: clients honor
  delete tombstones in their store merges and cache unions, so a
  bookmark deleted on one device no longer resurrects from another
  device's stale cache.
- Replaceable-event tie-breaks follow NIP-01 retention (lowest event id
  on a created_at tie), so every device renders the same copy the relay
  stores.
- The durable publish queue no longer drops a newer queued edit when an
  older save of the same URL is acknowledged.
- Bookmarked Nostr posts whose target event reaches the relay after
  first lookup now appear within the session instead of staying hidden.
- Opening an archive falls back to its recorded Blossom mirrors (with
  content-hash verification for public blobs) when the primary store
  is unavailable.
- Relay operations: deterministic write-policy rejections are
  dead-lettered for operator review instead of being retried into
  silence, and private-item delete tombstones share the private-state
  rate budget so bulk deletes cannot lose them.

Testing infrastructure:

- All test suites for every package now live under a repo-root
  `tests/` tree (982 passing tests across frontend, api,
  archive-worker, browser-extension, and bunker), documented in
  `tests/README.md` with per-finding regression guards under
  `tests/<package>/regression/` and a `tests/run-all.sh` runner.
