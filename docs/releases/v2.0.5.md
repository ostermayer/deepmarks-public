# Deepmarks 2.0.5

Deepmarks 2.0.5 focuses on sync durability:

- Bookmark saves and mutations become durable after signing and local
  retry-queue storage, so transient relay/API transport failures no
  longer show user-facing sync errors.
- Queued publishes retry in the background across web, mobile, and the
  browser extension.
- Extension direct-relay mode falls back to the Deepmarks retry queue
  when every direct relay rejects or times out.
- Mobile share-drain preserves local pending shares if durable queueing
  fails, preventing local-only saves from being treated as synced.
- Save and edit flows keep optimistic UI updates, with rollback only
  when the signed event cannot be made durable.
