# Deepmarks 0.7.5

Deepmarks 0.7.5 is a public source release for the playback/polish
wave, shipped in the installed-app 2.2.5 / extension 2.2.4 build lines.

- Streaming media playback: MP4-family media archives are remuxed to
  fragmented MP4 with probed RFC 6381 codecs; the client feeds
  decrypted chunks straight into a MediaSource buffer so playback
  starts with the first chunks. Blob fallback for everything else.
- The replication sidecar migrated from the deprecated `strfry stream`
  CLI to `strfry router` (config-driven, same semantics).
- /app/export includes bookmarks imported from other Nostr clients'
  NIP-51 lists, including bookmarked posts.
- One canonical replaceable-bookmark conflict rule
  (replaceableBookmarkWins) shared by the feed, the store, and mirrored
  by the extension — all surfaces resolve concurrent edits identically,
  matching NIP-01 relay retention.

Test suite: 1,027 passing tests; see tests/README.md.
