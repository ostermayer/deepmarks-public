# Deepmarks 0.6.5

Deepmarks 0.6.5 is a public source release for the private archive key
durability work shipped in the installed app and browser-extension
2.0.7 build line. The public source tag remains on the 0.x stream; the
native app and extension stores use their own monotonically increasing
versions.

- Private archive keys are synced as soon as an archive job is accepted,
  using a provisional `job:<jobId>` key before final blob-hash
  reconciliation completes.
- Private archive opening checks final blob keys, provisional job keys,
  and the local pending-key stash before reporting a missing key.
- Existing private archives with missing keys remain visible and can
  queue bounded replacement archives with fresh client-generated keys.
- Missing-key private archive repair runs even when archive-all is
  disabled.
- Browser extension archive saves and opens use the same private key
  recovery path as the mobile/web app.
- The release checklist now explicitly requires native, Zapstore, and
  extension rebuilds for client-side archive/key fixes.
