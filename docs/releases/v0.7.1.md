# Deepmarks 0.7.1

Deepmarks 0.7.1 is a public source release for round two of the June
2026 reliability work, shipped in the installed-app 2.2.1 build line
(browser extension stays on 2.2.0 — no extension code changed).

- Remote-signer (NIP-46/Amber) decrypt and encrypt calls time out
  instead of hanging the private-bookmark refresh forever when the
  signer is unreachable; failures are classified (signer-timeout,
  nip44-unsupported, wrong-key) and whole-set rewrites abort with an
  actionable error.
- The bookmarks view explains private-set decryption problems with a
  reason-specific banner and retry button, and shows a read-only hint
  when the session has a pubkey but no usable signer.
- Bookmarked Nostr posts whose target event is unreachable render a
  placeholder (with an external link and saved date) instead of
  nothing, and `note1…` / `nevent1…` / `nostr:` references pasted into
  the save box normalize to the canonical social URL instead of
  failing validation.
- Import pacing: kind:39701 bookmark writes get a dedicated env-tunable
  relay budget (default 1000/hour) instead of the shared 200/hour
  general bucket, rejected events no longer count against the budget,
  and rate-limited events retry on a 30-attempt budget so bulk imports
  drain fully.
- The admin dashboard's queue gauges watch the Redis keys the workers
  actually use (publish-relay queue/delayed/dead-letter, kind-1
  fanout) instead of a never-written key.
