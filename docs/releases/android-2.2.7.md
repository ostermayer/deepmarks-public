# Deepmarks Android 2.2.7

Archive clarity and reliability release.

- **Blocked archives are visible.** If a supported media or page archive
  fails because the source site blocks archiving, Deepmarks now shows a
  clear failed-archive marker instead of leaving the bookmark ambiguous.
- **Archive status is easier to trust.** Archive failures that are caused
  by site blocks are recorded for the user without creating unnecessary
  operator alerts.
