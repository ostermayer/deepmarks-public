# Deepmarks 0.6.3

Deepmarks 0.6.3 focuses on Android signer reliability and mobile polish:

- Adds Android NIP-55 background signer support for trusted apps, reducing repeated app-switch approval loops after the first trust decision.
- Adds Android signer permission management with full, medium, and low trust levels for connected Nostr apps.
- Supports private zap signer requests, including `decrypt_zap_event`, for compatible Android Nostr clients.
- Keeps signed-in native sessions on an app loading state instead of flashing the public welcome/sign-up screen during handoffs.
- Warms friends-feed previews earlier while scrolling so images and metadata appear sooner.
- Updates the Android launcher foreground so the Deepmarks pennant is centered and sized consistently.
