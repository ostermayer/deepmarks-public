# Deepmarks 0.6.4

Deepmarks 0.6.4 focuses on mobile wallet setup, zap reliability, and friends-feed preview performance:

- Adds mobile QR scanning for NWC wallet setup.
- Stores NWC wallet connections in native secure storage on iOS and Android, including Android sessions signed in through external signers.
- Allows zaps to continue when an LNURL provider returns a payable but non-verifiable invoice, while warning when a public NIP-57 receipt may not appear.
- Updates friends-feed zap totals immediately after successful in-app payments.
- Adds content-type detection for extensionless Blossom media so MP4 blobs can render as playable previews.
- Reduces friends-feed preview jank by prefetching metadata earlier and lazy-loading preview images.
