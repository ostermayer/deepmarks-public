# Deepmarks 0.7.4

Deepmarks 0.7.4 is a public source release for the post-structural
quality wave, shipped in the installed-app 2.2.4 / extension 2.2.3
build lines.

- CI: GitHub Actions runs all five package suites and typechecks
  (1,022 tests, including the shared-core byte-parity guard and the
  strfry writePolicy subprocess tests) on every push.
- Share-sheet support for nostr:/note1/nevent1 references on iOS and
  Android; e-tag note bookmarks from imported NIP-51 lists render in
  the main bookmarks list and search; public note refs get relay-hint
  prefetch.
- The re-sync tool is additive: it reads the relay first and publishes
  only missing bookmarks (public per-URL, private per-item), never
  resurrecting deletes or re-asserting stale state (closes SYNC-F3).
- Extension popup shows a locked notice instead of silently hiding
  private bookmarks; permanently-failed media archives are recorded and
  skipped instead of re-enqueued forever; the relay replica's freshness
  is monitored (live replication went operational this release —
  817k+ events, verified converged).
