# Deepmarks 0.7.2

Deepmarks 0.7.2 is a public source release for rounds three and four of
the June 2026 reliability work plus a code-simplification pass, shipped
in the installed-app 2.2.2 / extension 2.2.1 build lines.

- Cross-device public-delete propagation: the feed keeps a session
  deletion memory (with NIP-09 author validation) and prunes the
  merge-only server cache, so deletes no longer resurrect from stale
  caches or out-of-order relay delivery.
- Offline-queue safety: replaceable events are re-stamped/re-signed at
  drain time, offline and locked-signer drains don't burn the bounded
  retry budget, and the bookmarks view shows a waiting-to-sync count.
- Extension parity: edits preserve archive linkage tags (pinned
  tag-for-tag against the web builder by a cross-package test),
  direct-mode publishes require the canonical relay, and the durable
  queue drains from the background service worker.
- Archive-key lifecycle: NIP-44 signer gating at private/media enqueue,
  publish-aware stash sweeping (unpublished keys kept 90 days and
  retried), and missing-key archives surfaced + re-archived (media
  included) instead of hidden.
- Archive-worker self-repair: the audit pass re-notifies lost success
  callbacks, attempts Wayback rescues for failed public archives, and
  marks lost encrypted jobs failed so clients can retry.
- Operator visibility: dead-letter alerting, a relay write-health
  probe (GET /health/relay, wired into the uptime checker), LMDB
  map-size monitoring, a pinned strfry build, and a 10-year
  old-event window so onboarding imports stop bouncing.
- Cleanup: verified-dead code removed, stale release docs fixed, the
  AMO build script reconciled with the npm release script.

Test suite: 1,017 passing tests; see tests/README.md.
