# Deepmarks 0.7.6

Deepmarks 0.7.6 is a public source/server release for the archive
reliability and release-pipeline cleanup wave, shipped with Android /
Zapstore app version 2.2.7.

- Archive failures are clearer to users: supported media/page URLs that
  cannot be captured because the source site blocks archiving now show a
  failed-archive marker instead of sitting in an ambiguous state.
- Operator archive alerts are quieter: expected page failures, stale jobs
  marked lost by archive audit, and replaceable relay events superseded by
  newer events are recorded without sending warning emails for each item.
- Archive operations are steadier: Box B archiving is backed by attached
  storage and reduced worker concurrency, and archive health continues to
  report queue/audit state for real operational issues.
- Public release tooling was hardened: the public mirror export now uses a
  portable Git initialization flow, an explicit SSH remote, and additional
  sanitization for operator host examples before publishing to
  `deepmarks-public`.

Installed Android / Zapstore build: 2.2.7 (`versionCode` 37).
