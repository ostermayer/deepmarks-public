# Deepmarks Android 1.5

- Explore now opens as a stable result list instead of prompting to merge live relay updates.
- Explore can filter newest, popular, tags, and custom tag views by all time, year, month, week, 24h, or a custom date range.
- Pull-to-refresh returns the native app to the top of the refreshed list.
- Adds planning documentation for the upcoming opt-in Android foreground NIP-46 signer service.
