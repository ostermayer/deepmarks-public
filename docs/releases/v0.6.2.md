# Deepmarks 0.6.2

Deepmarks 0.6.2 focuses on feed usability:

- App section tabs and sort bars stay visible while scrolling.
- Friends-feed rows can display direct media previews and inline playback for video/audio links.
- Friends-feed zap totals now use the original social note event id, matching zaps that happen outside Deepmarks.
- Native mobile apps keep RSS/Atom icons hidden while web feed pages expose them.
