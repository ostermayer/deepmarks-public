# Deepmarks 0.6.1

This release expands Deepmarks' Nostr-native discovery model with
friends feeds, efficient link previews, and public Atom feeds.

## Friends

- Users can select a Deepmarks friends subset from their NIP-02 contact
  list using a public NIP-51 `kind:30000` follow set.
- `/app/friends` shows public `kind:39701` bookmarks from selected
  friends and links extracted from those friends' public `kind:1` notes.
- Social-note links stay scoped to friends feeds. They do not enter
  global recent, popular, public profile, or browser extension feeds.
- Friends links can be saved, shared to Nostr, and zapped without first
  saving them to the user's own library.

## Previews And Feeds

- Friends links render server-light rich previews: direct image previews,
  click-to-play audio/video, YouTube thumbnails, and cached webpage
  snippets.
- Public Atom feeds now cover recent, popular, tags, user profiles, and
  friends feeds.
- Feed icons appear on web feed pages only. Native iOS and Android shells
  do not show RSS/Atom subscription controls.

## Mobile

- Android and iOS app metadata are synchronized at app version `1.7`
  with build number `8`.
- The native bottom navigation keeps Friends as a primary tab and keeps
  secondary sections under More.

## Verification

- `frontend`: Svelte check and targeted friends/zap/preview tests.
- `payment-proxy`: full test suite, including Atom feed route coverage.
