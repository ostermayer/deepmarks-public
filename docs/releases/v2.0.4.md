# Deepmarks 2.0.4

Deepmarks 2.0.4 focuses on mobile share-sheet durability and private
bookmark interoperability:

- Lets iOS and Android share sheets publish private/default-private saves
  directly when the local key is available, without requiring the host
  app to open first.
- Adds encrypted `kind:30003` private-item events for native mobile
  shares and merges them with the existing chunked private bookmark set.
- Publishes encrypted private-item tombstones on private delete so a
  standalone mobile share cannot reappear after removal.
- Keeps native share ordering stable with `published_at_ms` and mirrors
  already-published mobile shares into local state without duplicate
  relay posts.
- Updates Chrome/Firefox extension readers to understand mobile private
  items, packaged as extension version 1.3.3.
