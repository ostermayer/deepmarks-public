# Deepmarks Android 1.8

This release tightens the reading experience in the mobile app:

- Keeps the section navigation and sort row visible while scrolling.
- Shows lightweight direct media previews for image, video, and audio links without scraping those URLs.
- Shows zap totals on friends-feed links using the original Nostr note event, so social zaps outside Deepmarks are reflected in the feed.
- Keeps the friends-feed RSS/Atom UI web-only.
