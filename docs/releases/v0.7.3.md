# Deepmarks 0.7.3

Deepmarks 0.7.3 is a public source release for the four structural
reliability projects, shipped in the installed-app 2.2.3 / extension
2.2.2 build lines.

- Per-item private bookmark events: saves/edits/deletes publish one
  small encrypted replaceable event per bookmark instead of rewriting
  the whole chunked set — concurrent multi-device edits can no longer
  clobber each other, and the library-wipe failure class is
  structurally eliminated on the write path.
- Shared private-set core: the chunk-selection/merge logic (the code
  whose drift caused the original production wipe bug) now lives in one
  byte-identical file in both the web app and the extension, locked
  together by a checksum test.
- Chunked media-archive encryption (format v2): media blobs are
  encrypted in independently-authenticated ~8 MiB AES-GCM chunks (AAD
  binds index + final flag), and the client stream-decrypts into a
  disk-backed Blob with bounded memory — large paid media archives are
  now playable on iOS. Upload timeouts scale with blob size; v1 blobs
  keep working.
- Live relay replication: a strfry-stream sidecar on the relay box
  pushes every stored event to a VPC-only replica within seconds,
  cutting the relay's recovery point from the nightly export (~24h)
  to near-zero.

Test suite: 1,022 passing tests; see tests/README.md.
