# Deepmarks 2.0.1

Historical client-aligned release record. The active public GitHub source
release stream is now the `v0.6.x` series; installed apps and extension
packages keep their own monotonically increasing store versions.

Deepmarks 2.0.1 focuses on making the mobile apps feel complete for daily Nostr use:

- Adds Android signer support so Deepmarks can work with apps that use Android Nostr signers.
- Adds Android signer login support so Deepmarks can use installed signers such as Amber or Primal.
- Aligns mobile navigation across iOS and Android with bottom-tab search, posts, read-later, friends, bookmarks, and customizable mobile tabs.
- Improves Nostr Wallet Connect setup on mobile, including QR scanning and native secure storage.
- Improves the friends feed so it defaults to friends' saved bookmarks across `39701`, `10003`, and `30003`, with raw `kind:1` social-post links available as an opt-in gear setting.
- Adds zap-sats sorting and public-relay zap totals for bookmark feeds, friends bookmarks, saved posts, tags, and explore views.
- Improves friends-feed performance with cached identities, cached feed rows, richer previews, video thumbnail fallbacks, and less disruptive refresh behavior.
- Saves friends-feed Nostr posts as full source notes in the Posts category while preserving extracted link and media previews.
- Fixes private archive opening for private media archives and improves archive media format handling for new video archives.
- Keeps imported bookmark ordering stable by preserving original timestamps during import and display.
